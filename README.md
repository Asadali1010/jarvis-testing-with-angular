# Jarvis Testing Application

This is an Angular application designed for testing and implementation of modern Angular patterns, including Server-Side Rendering (SSR) and a hybrid styling approach with Tailwind CSS 4 and Bootstrap 5.

## Tech Stack
- **Framework**: Angular v22
- **Styling**: Tailwind CSS v4, Bootstrap v5
- **Testing**: Vitest
- **SSR**: Angular SSR with Express

## Getting Started

### Installation
```bash
npm install
```

### Development
```bash
npm start
```

### Testing
```bash
npm test
```

### SSR Deployment
```bash
npm run build
npm run serve:ssr:jarvis-testing-application
```
